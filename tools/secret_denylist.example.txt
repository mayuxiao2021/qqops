# 本机隐私禁词表(这是**格式说明**, 真实值只写在本地: tools/secret_denylist.txt)
#
# 为什么要有它: 通用规则只能抓"长得像密钥"的东西, 抓不住"你的 QQ 号/群号/设备号/昵称"
# 这类**本身合法、但只属于你**的信息。把真实值写进本机文件后, 任何提交只要包含它们就会被拦下。
#
# 用法:
#   1) cp tools/secret_denylist.example.txt tools/secret_denylist.txt
#      (tools/secret_denylist.txt 已在 .gitignore 里, 不会入仓)
#   2) 每行一个词, 至少 4 个字符; # 开头是注释
#   3) 之后照常开发: python3 tools/check_secrets.py --staged(或让 pre-commit 钩子自动跑)
#
# 建议放进去的内容(**下面全是假值, 请换成你自己的**):
# 100000001             # 我的 QQ 号
# 100000002             # 我常看的群号
# 100000003             # 另一个群号
# aaaa1111bbbb2222      # 控制台令牌(data/config.json 的 web.token)
# my-napcat-token       # NapCat API 令牌
# cccc3333dddd4444      # NapCat WebUI 令牌
# SERIAL0000000001      # 手机设备序列号(adb devices 里那串)
# u0_a000               # 手机上的 Linux 用户名(adb shell 里能看到)
# 000000                # SSH 密码之类的口令
# MyBotNickname         # 机器人 QQ 昵称
# 张三                  # 我的真名(不该出现在公开仓库里)
#
# 注意: 不要把"本来就该出现在公开仓库里的东西"写进来 —— 例如你的 GitHub 用户名(README 里的
# 仓库地址要用)、通用词(如 qqops、napcat、termux), 否则会满屏误报。
#
# 顺带一提: 这个文件本身也被扫描。**别把真值写在这里** —— 这份是要进仓库的模板。
