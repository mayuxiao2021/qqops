# 本机隐私禁词表(这一行说明可以留, 但真实值只在本地: tools/secret_denylist.txt)
#
# 为什么要有它: 通用规则只能抓"长得像密钥"的东西, 抓不住"你的 QQ 号/群号/设备号/昵称"
# 这类**本身合法、但只属于你**的信息。把真实值写进本机文件后, 任何提交只要包含它们就会被拦下。
#
# 用法:
#   1) 复制成 tools/secret_denylist.txt(该文件名已在 .gitignore 里, 不会入仓)
#   2) 每行一个词, 至少 4 个字符; # 开头是注释
#   3) 之后照常开发: python3 tools/check_secrets.py --staged(或让 pre-commit 钩子自动跑)
#
# 建议放进去的内容(示例格式, 请把下面的假值换成你自己的):
# 3185307078            # 我的 QQ 号
# 156684507             # 我常看的群号
# 1067020738            # 另一个群号
# z95ggeqbpczbpu98mmh2d3b8   # 控制台令牌
# napcat-api-3000       # NapCat API 令牌
# 645a7aa9d88c          # NapCat WebUI 令牌
# AMRF026304000862      # 手机设备序列号
# u0_a357               # 手机上的 Linux 用户名(adb shell 里能看到)
# 114514                # SSH 密码
# 挽月                  # 机器人 QQ 昵称
# 马宇霄                # 我的真名(不该出现在公开仓库里)
#
# 注意: 不要把"本来就该出现在公开仓库里的东西"写进来 —— 例如你的 GitHub 用户名(README 里的
# 仓库地址要用)、通用词(如 qqops、napcat、termux), 否则会满屏误报。
