# 控制台

控制台是这套程序的门面:手机浏览器打开就能看清"消息进来了吗 / 服务活着吗 / 报告出了吗 / 出过什么错",
还能直接用一句话问记录。**默认只监听 `127.0.0.1`**, 电脑访问请用 `adb forward tcp:8091 tcp:8091`。

打开方式:`qqops url` 会打印带令牌的完整地址;令牌也在 `data/config.json` 的 `web.token`。

## 一级导航(10 页)

| 页面 | 回答的问题 | 主要操作 |
|---|---|---|
| 📊 **仪表盘** | 现在整体怎么样? | 立即总结 / 重载插件 / 跳运维;服务健康、今日消息量、最近报告、告警 |
| 💬 **对话** | 记录里到底有什么? | 提问、看来源原文、切换/删除会话;右侧有"QQ 里也能问"的入口与卡片测试 |
| 🗂 **消息** | 群里说了什么? | 全文检索(命中高亮)、按群/类型/时间筛、分页、导出 CSV |
| 📝 **总结** | 报告出了吗?内容是什么? | 阅读、导出 Excel/Word、网页版报告 |
| ⏱ **任务** | 什么时候跑?上次结果? | 改定时(每天定点/间隔/每周)、立即执行、看历史与费用 |
| 🧩 **插件** | 有哪些能力?怎么配? | 启用停用、改配置(带说明的表单)、重载、看命令与定时任务 |
| 🗃 **数据** | 攒下了什么? | 群组开关、事件/待办、长期记忆(可"看原文")、链接、媒体 |
| 🛠 **运维** | 服务活着吗?出过错吗? | 启停服务、**资源与功耗**、崩溃账本、实时日志、框架自检、备份 |
| ⚙ **设置** | 怎么改行为? | 分组配置(每项都有中文说明)、令牌、模型、推送、端口 |
| ❓ **帮助** | 怎么用?出问题怎么办? | 快速上手、命令速查、常见问题、关于 |

手机浏览器上底部有标签栏(仪表盘/对话/消息/总结/运维),其余从「更多」抽屉进入。

## 几个常用操作

### 第一次进来

1. **群组** → 勾选参与总结的群(默认只存你勾的群;不勾 = 什么都不总结);
2. **设置** → 填模型 `base_url` / `api_key` / `model`;
3. **任务** → 设定时间, 点「试运行(不花钱)」确认能组装出提示词;
4. **运维 → 自检** → 一键跑完环境/存储/服务/适配器/模型的检查。

### 出问题时

- **运维 → 服务**:每个服务一行, 有进程号、端口应答、内存、运行时长;可单独启停/重启;
- **运维 → 账本**:异常按组件与类型聚合, 点「详情」看完整堆栈;崩溃循环(反复崩到熔断)会标红;
- **运维 → 日志**:实时流(按模块/级别过滤、可暂停), 顶部有 `record` 编号可对号入座;
- **运维 → 自检**:框架自检(角色、事件总线、管线阶段、插件状态)与「一键诊断」;
- **运维 → 资源**:运行形态(单/多进程)、内存、功耗档位、进程列表、合并效果对比。

### 改配置

「设置」页是**表单驱动**的:每一项都带中文说明与默认值, 密钥显示为掩码(留空=不修改)。
保存后需要重启的服务会自动重启, 页面顶部会给出提示。危险操作(停止服务/清空账本/删除数据)
都要二次确认。

## 接口与鉴权

- 所有接口都要令牌:URL 里的 `?token=` 会存进 `sessionStorage`, 请求带 `X-Token` 头;
  同时下发 HttpOnly 会话 Cookie(浏览器禁用 Cookie 时靠 `X-Token` 也能用);
- 令牌失效会跳登录页;页面上的错误卡片会给出原因与 `record`, 不会整页白屏;
- 接口统一返回 `{ok, data, error, rid}`;想看完整接口清单:「运维 → 自检」里的路由列表。

## 界面约定

| 场景 | 表现 |
|---|---|
| 加载 | 卡片级骨架屏(>300ms 才显示, 避免闪烁) |
| 空态 | 说明"为什么空 + 怎么产生数据"并给一个直达按钮 |
| 失败 | 卡片内红框 + 原因 + 重试;**不整页崩**, 其它卡片照常 |
| 长操作 | 按钮进入 loading 并禁用, 完成后自动刷新相关卡片 |
| 危险操作 | 弹窗:标题 + 影响说明 + "我确认" → 才可点确认 |
| 深色模式 | 跟随系统, 可手动切换并记住 |
| 自动刷新 | 默认按功耗档位(省电档 60 秒), 可在设置里关 |

页面级细节(每个卡片显示什么、为什么这么排)见[控制台规划](/CONSOLE)。
