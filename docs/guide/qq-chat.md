# 在 QQ 里直接问

不用打开控制台:在 QQ 聊天窗口里发一句话, 机器人把答案回到聊天里。

```
你(私聊) : 昨天群里谁提到报告?
机器人    : 昨天 12:03 小明说"这次报告要加一页预算表" [M1]
            ── 引用你的提问, 末尾附来源
```

## 触发规则

| 场景 | 触发方式 | 默认 |
|---|---|---|
| **私聊** | 直接发问题(不需要前缀) | ✅ 开启, 但**仅限白名单** |
| **群聊** | 必须带前缀:`问 谁要交报告` / `ai …` / `/ai …` / `? …` | ❌ 关闭(怕打扰 + 隐私) |

白名单默认 = 「推送」里配置的主人 QQ。**既没配白名单也没配主人 QQ 时一律不响应** ——
免得陌生人把你的模型额度烧光(真机上实测:陌生人来私聊会被计数为 `skipped`, 不调用模型)。

## 配置(控制台 → 插件 → 智能查询 → 「在 QQ 里直接问」)

| 项 | 默认 | 说明 |
|---|---|---|
| 启用聊天内问答 | 开 | 关掉后只有控制台能问 |
| 允许提问的 QQ 号 | 空 | 留空 = 只有主人 QQ |
| 群里的触发前缀 | `问, ai, /ai, ?` | 私聊不需要前缀 |
| 允许在群里问 / 允许提问的群号 | 关 / 空 | 两个条件都要满足才回应 |
| 回答形态 | `text` | `text` 纯文本 / `forward` 合并转发卡片 / `card` 签名卡片+文本 |
| 引用提问再回答 | 开 | 用 `reply` 消息段引用你的问题 |
| 附来源编号 | 开 | 回答末尾附 `[M1] 10-10 12:03 小明` |
| 同一人最短间隔 | 5 秒 | 0 = 不冷却 |
| 失败时回一句原因 | 开 | 例如额度用完、模型不可用 |
| 默认时间范围 | 0 | 0 = 用「查询设置」里的默认值 |

## 追问

每个 QQ(或每个群)对应**一个固定会话**, 所以在 QQ 里可以接着问:

```
你 : 谁要交实验报告?
机器人: …(回答)
你 : 那截止时间呢?          ← 会接着上一轮的上下文
```

这些会话会出现在控制台「对话」页(标题形如"某某 的 QQ 提问"), 你可以像普通会话一样查看/删除。

## 前提:私聊事件要能进得来

采集器有个开关 **「私聊不入库也交给插件」**(默认开):私聊内容**不落库**(隐私),
但要交给插件处理, 否则问答收不到消息。两种取向:

| 想要 | 配置 |
|---|---|
| 私聊内容完全不存, 但能用问答 | 保持默认(`store_private=false` + `command_private=true`) |
| 私聊也进库、也参与总结 | 打开「也保存私聊消息」 |
| 私聊完全不理 | 关掉「私聊不入库也交给插件」 |

## 关于卡片

| 形态 | 实测 |
|---|---|
| `text` 纯文本 | ✅ 所有版本可用(默认) |
| `forward` 合并转发卡片 | ✅ 所有版本可用, 内容任意, 长答案最合适 |
| `card` 签名卡片 + 文本 | ⚠️ 需要 NapCat 的 PacketBackend 支持当前 QQ 版本, 否则自动退文本 |
| 自己拼的 JSON 卡片 | ❌ 新版 QQ 提示"卡片版本过低"(需要签名) |

控制台「对话」页有 **「测试卡片渲染」**:一次把几种卡片发到你的 QQ 并列出成功/失败原因,
用眼睛确认哪种能显示。技术细节见[卡片与聊天问答](/CHAT)。

## 常见问题

| 现象 | 处理 |
|---|---|
| 私聊没反应 | 确认发消息的 QQ 在白名单里;`qqops status` 看服务;看采集指标里 `skipped` 是否在涨 |
| 群里没反应 | 三个条件:允许群问答=开、群号在白名单、消息带前缀 |
| 回复太长/太短 | 调「单条回复上限」;回答内容由问题与记录量决定 |
| 被自己的消息刷屏 | 机器人自己的消息(`message_sent`)不会触发问答, 不会自我循环 |
