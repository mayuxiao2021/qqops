# QQOps 控制台规划(v3)

> 控制台是这套程序的门面:手机浏览器打开就能看清"消息进来了吗 / 服务活着吗 / 报告出了吗 /
> 出过什么错"。本文件定义**信息架构**与**交互规范**,实现落在 `qqops/console/`。

---

## 1. 设计目标

| 目标 | 具体要求 |
|---|---|
| 一眼看懂 | 打开首页 3 秒内知道:服务健康、今日消息量、最近报告、有没有告警 |
| 手机优先 | 375px 宽可用;主要操作单手可点;无横向滚动;触控目标 ≥ 44px |
| 失败不白屏 | 任何接口失败只降级对应卡片并给出原因 + request-id,不整页崩 |
| 操作有反馈 | 每个动作有:进行中 → 成功/失败 toast → 数据自动刷新 |
| 危险动作防误触 | 停止服务/删除数据/清空账本:二次确认 + 影响说明 |
| 零依赖 | 单页 + 原生 JS,不用构建工具,断网可用(静态资源本地化) |

## 3. 页面规格

### 3.1 仪表盘
- **顶部状态条**:整体健康(●全部正常 / ◐部分异常 / ○未运行)+ 当前告警数 + 版本号
- **卡片:服务**(collector / scheduler / web / watchdog / napcat):进程号、端口应答、心跳、重启次数
- **卡片:今日概览**:消息数(24h 趋势迷你图)、活跃群数、报告数、待办/事件数
- **卡片:最近报告**:最近 3 份(标题/字数/时间/一键预览)
- **卡片:异常与崩溃**:最近 5 条(组件/异常/时间),一键跳运维页
- **快捷操作**:立即总结、重启服务、重载插件、导出今日报告

### 3.2 消息
- 顶部搜索框(FTS,支持中文)+ 过滤(群、类型、时间范围、含媒体)
- 列表:时间 / 群 / 发送者 / 内容摘要 / 媒体缩略标识
- 点击展开详情(全文、图片、链接、文件);支持复制与跳转到该群当日总结
- 底部:分页(每页 50)+ 导出当前筛选(xlsx)

### 3.3 总结
- 列表:日期 / 群范围 / 字数 / 事件数 / 待办数 / 状态(成功/降级/失败)
- 详情:Markdown 渲染 + 原始 md 下载 + docx/xlsx 导出 + 推送状态 + token 成本
- 操作:重新生成(可选时间窗与群)、推送到 QQ、删除

### 3.4 任务
- 计划卡:模式(每天/每隔 N 分钟/每周)、时间列表、跳过条件(无新消息/最小条数)
- 下次运行时间(倒计时)+ 立即执行
- 运行历史:开始/结束/状态/耗时/错误摘要;失败可"重试"
- 维护任务:备份、清理、索引重建、媒体补抓

### 3.5 插件
- 卡片列表:显示名 / id / 版本 / 作者 / 描述 / 状态(启用·停用·加载失败)/ 优先级
- 每卡:启用停用开关、配置入口、重载按钮、查看日志、插件自带页面入口
- 配置:由 `_conf_schema.json` 生成(分组、类型、默认值、说明、hint、枚举、密钥掩码)
- 失败插件:红色卡片 + 失败原因 + "查看账本"

### 3.6 数据
- 标签页:事件 / 记忆 / 链接 / 媒体 / 文档
- 通用能力:搜索、按时间/群过滤、批量删除、导出 CSV
- 媒体:缩略图网格 + 点击大图 + 多模态描述文本

### 3.7 运维
- **服务控制**:每个服务一行(状态灯/进程号/端口/心跳/操作:启动·停止·重启)
- **旁路服务**:NapCat / AstrBot(启停、端口、说明)
- **崩溃账本**:表格(时间/组件/类型/异常/次数)+ 一键清空 + 复制详情
- **实时日志**:选择模块,自动滚动,支持暂停/级别过滤/关键字高亮/下载
- **备份与恢复**:立即备份、备份列表、恢复(二次确认)、清理旧备份
- **诊断**:一键 doctor,分组展示(环境/配置/存储/服务/适配器/模型/手机保活)

### 3.8 设置
- 分组折叠:采集 / 总结 / 计划 / 推送 / 控制台 / 看门狗 / 提取与富化 / 附件
- 每项:标签(中文)、当前值、默认值、说明、校验提示;密钥类显示"已配置"
- 危险区:重置配置、清空数据(二次确认 + 输入确认词)
- 导入/导出配置(JSON)

### 3.9 帮助
- 快速上手 5 步、命令速查(`bin/qqops *`)、常见问题(启动不了/收不到消息/报告没出/推送失败)、关于(版本/构建时间/数据目录)

## 4. 交互规范

| 场景 | 规范 |
|---|---|
| 加载 | 骨架屏(卡片级),>300ms 才显示,避免闪烁 |
| 空态 | 说明"为什么空 + 怎么产生数据",给一个直达操作按钮 |
| 错误 | 卡片内红框 + 原因 + `request-id` + "重试"按钮;不阻断其它卡片 |
| 成功/失败 | 顶部 toast 3 秒自动消失;失败 6 秒并可复制错误 |
| 长操作 | 按钮进入 loading 且禁用,禁止重复提交;返回后自动刷新相关卡片 |
| 危险操作 | 弹窗:标题 + 影响说明 + "我确认"复选框 → 才可点确认 |
| 键盘 | `/` 聚焦搜索、`g d` 仪表盘、`g o` 运维、`r` 刷新当前页、`Esc` 关闭弹窗 |
| 无障碍 | 语义化标签、`aria-live` 播报 toast、焦点可见、颜色不是唯一信息载体 |
| 深色 | `prefers-color-scheme` 自适应,提供手动切换并记住 |
| 时间 | 相对时间(3 分钟前)+ 悬浮显示绝对时间;时区取设备 |

---

## 5. 技术实现约定

- 一个 HTML 外壳 + `app.js` 路由(`#/page`),不用框架、不用构建
- 所有请求带 `X-Token`(来自 URL `?token=` 或 sessionStorage);401 → 显示登录页
- 静态资源内容指纹(`ASSET_VER`),避免手机浏览器缓存旧版
- 接口统一返回 `{ok, data, error, rid}`;前端统一处理错误
- 插件页面:后端 `@page` 返回页面元数据,前端渲染为导航项 + iframe/内嵌视图
