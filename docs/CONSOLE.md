# QQOps 控制台规划(v3)

> 控制台是这套程序的门面:手机浏览器打开就能看清"消息进来了吗 / 服务活着吗 / 报告出了吗 /
> 出过什么错",还能直接用一句话问记录。本文件定义**信息架构**与**交互规范**,
> 实现落在 `qqops/console/` 与 `qqops/static/`。

---

## 1. 设计目标

| 目标 | 具体要求 |
|---|---|
| 一眼看懂 | 打开首页 3 秒内知道:服务健康、今日消息量、最近报告、有没有告警 |
| 能问能答 | 不确定的事直接问:答案必须带来源编号,点开可核对原文 |
| 手机优先 | 375px 宽可用;主要操作单手可点;无横向滚动;触控目标 ≥ 44px |
| 失败不白屏 | 任何接口失败只降级对应卡片并给出原因 + request-id,不整页崩 |
| 操作有反馈 | 每个动作有:进行中 → 成功/失败 toast → 数据自动刷新 |
| 危险动作防误触 | 停止服务/删除数据/清空账本:二次确认 + 影响说明 |
| 零依赖 | 单页 + 原生 JS,不用构建工具,断网可用(静态资源本地化) |

## 3. 页面规格

### 3.1 仪表盘
- **顶部状态条**:整体健康(●全部正常 / ◐部分异常 / ○未运行)+ 当前告警数 + 版本号
- **卡片:服务**(collector / scheduler / web / watchdog / napcat):进程号、端口应答、心跳、重启次数
- **卡片:今日概览**:消息数(24h 趋势迷你图)、活跃群数、报告数、待办/事件数
- **卡片:最近报告** / **异常与崩溃**(最近 5 条,一键跳运维)/ **快捷操作**

### 3.2 对话(智能查询)
- **左侧会话列表**:标题(首问前 40 字)、轮次数、时间;支持新建/切换/删除
- **问答气泡**:用户问题右对齐;回答左对齐,含
  - **内联来源编号** `[M3]`(可点,弹窗显示原文)
  - **来源芯片行**:💬消息 / 📌待办 / 🧠记忆 / 🔗链接 / 🖼媒体,悬浮显示摘要
  - **元信息**:模型名、token 进/出、检索轮次、耗时、是否降级
- **空态**:说明能问什么 + 4 条**从真实记录生成的推荐问题**(不用模型,省额度)
- **输入区**:多行输入(Enter 发送 / Shift+Enter 换行)、时间范围下拉、状态提示、清屏
- **额度**:显示"今日已用 x/y",达到上限给出明确提示
- **降级**:模型不可用时不留白 —— 直接列出检索命中的记录,并说明模型不可用

### 3.3~3.10
(消息/总结/任务/插件/数据/运维/设置/帮助 与 v3 相同;消息页对 `recalled` 显示「已撤回」标记,
`self` 显示「机器人」标记。)

### 3.11 运维 → 资源(v3.2 新增页签)

回答"这套东西现在占多少资源、还能不能更省"。顶部一行结论,下面四块:

| 区块 | 内容 | 数据来源 |
|---|---|---|
| 形态 | 单进程/多进程徽标、pid、自身 RSS、启动时间与运行时长 | `GET /api/ops/resources` → `runtime` |
| 档位 | 当前档位(性能/均衡/省电)+ 已展开的四个节拍、SQLite 缓存、富化窗口;三个按钮直接切档 | `power` |
| 进程 | 进程列表(pid / RSS / 命令行)、合计进程数与合计内存 | `processes` `totals` |
| 合并效果 | 合并前后进程数与内存对比结论 | `estimate.note` |

- 切换形态/档位 → `POST /api/ops/power` → 后端**脱离请求进程**重启实例 →
  页面提示"已切换,正在重启",刷新后回显新形态(重启期间接口短暂不可用属正常)。
- 单进程下四个服务共享同一 pid,列表里按 pid 去重显示一次,仪表盘的服务卡片仍逐个显示状态。
- 省电档生效后,页面刷新间隔自动跟随 `console_refresh`(省电档 60s),避免手机端无谓轮询。

## 4. 交互规范

| 场景 | 规范 |
|---|---|
| 加载 | 骨架屏(卡片级),>300ms 才显示,避免闪烁 |
| 空态 | 说明"为什么空 + 怎么产生数据",给一个直达操作按钮 |
| 错误 | 卡片内红框 + 原因 + `request-id` + "重试"按钮;不阻断其它卡片 |
| 成功/失败 | 顶部 toast 3 秒自动消失;失败 6 秒并可复制错误 |
| 长操作 | 按钮进入 loading 且禁用,禁止重复提交;返回后自动刷新相关卡片 |
| 危险操作 | 弹窗:标题 + 影响说明 + "我确认"复选框 → 才可点确认 |
| 键盘 | `/` 聚焦搜索、`g d` 仪表盘、`g o` 运维、`r` 刷新当前页、`Esc` 关闭弹窗 |
| 无障碍 | 语义化标签、`aria-live` 播报 toast、焦点可见、颜色不是唯一信息载体 |
| 深色 | `prefers-color-scheme` 自适应,提供手动切换并记住 |
| 时间 | 相对时间(3 分钟前)+ 悬浮显示绝对时间;时区取设备 |

## 5. 技术实现约定

- 一个 HTML 外壳 + `app.js` 路由(`#/page`),不用框架、不用构建
- 所有请求带 `X-Token`(来自 URL `?token=` 或 sessionStorage);401 → 显示登录页
- 静态资源内容指纹(`ASSET_VER`),避免手机浏览器缓存旧版
- 接口统一返回 `{ok, data, error, rid}`;前端统一处理错误
- 插件页面:后端 `@page` 返回页面元数据,前端渲染为导航项 + iframe/内嵌视图
